Proposed Directory Structure
ocean-vortex/
├── .github/              # CI/CD Workflows

├── src/                  # Production Code (The "Source")
│   └── ocean_vortex/     # Core Package

│       ├── core/         # Domain Models & Business Logic

│       └── scripts/      # Utility CLI scripts
├── tests/                # Parallel Test Suite
│   ├── unit/
│   └── integration/
├── .env.example          # Environment Template
├── Dockerfile            # Multi-stage optimized build
├── pyproject.toml        # Dependency & Tool Config
└── README.md             # Technical Onboarding

Senior Benefits

  • Surgical Isolation: Business logic is separated from FastAPI routes.

  • Standardization: Familiar to any engineer coming from Google, Meta, or Amazon.
